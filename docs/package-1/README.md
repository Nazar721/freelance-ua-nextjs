## Адреса локального перегляду

Production-збірка запущена локально:

```bash
npm run build   # поточний стан коду
npm run start   # http://localhost:3011
# або розробка: npm run dev  → http://localhost:3010
```

- Реєстр: `docs/package-1/registry.md` (таблиці + «Потребує ручної звірки» + «Медіа з повторним використанням»)
- Очікування: `docs/package-1/expectations.json`
- Повторна генерація та перевірка:

```bash
node scripts/inventory.mjs
node scripts/check-urls.mjs --base http://localhost:3011 --mode baseline --out docs/package-1/baseline/check-report.json
node scripts/check-urls.mjs --base http://localhost:3011 --mode acceptance   # очікується FAIL до Пакетів 2–3
```

## Погоджені рішення для Пакета 2 (від власника)

- Мова визначається URL (UA без префікса, EN з `/en/`).
- Повний UA/EN обсяг залишається затвердженим.
- `x-default` поки не додаємо.
