## Нормалізація параметрів каталогу

| Старий URL | Поведінка | Рішення |
|---|---|---|
| `/cases?tab=it\|design\|video` | фільтр клієнтським скриптом, canonical → `/cases` | лишити параметр як фільтр; не SEO-сторінка |
| `/cases?tab=design&type=photo-retouch` | підфільтр | лишити як фільтр; не окремий canonical |
| `/cases?tab=...&type=ecommerce\|landing\|saas-telegram` | підфільтр IT | аналогічно |
| `/cases?tab=...&type=reels\|motion\|youtube\|ai` | підфільтр відео | аналогічно |

Правило: параметри `tab`/`type` — суто сортування/відображення. Вони не породжують окремі SEO-сторінки, canonical завжди веде на основний вміст (`/cases` або сторінка напряму).
